How to interpret these results

These estimates are generated by an experimental neural network trained on synthetic data. Lower cardiotoxicity risk alone does not determine the best cancer treatment.

01 — DATA

Synthetic patient population

Trained on 10,000 simulated observations incorporating receptor status, mutation status, cancer stage, age, and troponin.

02 — MODEL

Multi-head neural network

A shared representation feeds three treatment-specific output heads. This browser demo uses separately retrained weights based on the notebook's three-head architecture. Its predictions and checkpoint are not identical to the repository notebook's saved results.

03 — PURPOSE

Exploratory risk comparison

Illustrates patient-level treatment-risk comparisons and an interactive model interface—not a validated clinical decision tool.

Research prototype only.All predictions are based on a model trained with simulated records and may not reflect real-world treatment outcomes. No clinical validation has been performed. The evaluation metrics in the GitHub README refer to the repository notebook, not this separately retrained browser model. Do not use for medical decisions. Model estimates do not account for treatment efficacy, actual drug or dose, or individual clinical circumstances.
